Selection Translate

Select text anywhere → translate · save · check grammar

Paste the web app URL from your sheet's Apps Script deployment. Selections you save go straight into it, and the sheet fills in pronunciation and the English definition.

Grammar checks run on LanguageTool. Leave the address blank for the free public server, or point it at your own (http://localhost:8010) to skip the rate limits. LanguageTool has no Vietnamese rule set.
